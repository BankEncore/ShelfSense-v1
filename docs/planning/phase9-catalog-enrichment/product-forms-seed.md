# Product forms seed

Status: **Accepted** with Phase 9 Slice 3.

Codes are unique, immutable, exactly two uppercase letters. Staff may edit `name`, `display_order`, and `active`. New codes are seed-only.

Seed order is `display_order` 10, 20, 30, … in this sequence:

| Code | Name |
|---|---|
| AU | Audio (format not specified) |
| BA | Bathbook |
| BB | Board Book |
| BG | Board Game |
| BM | Bookmark |
| BX | Box or Slipcase |
| CA | Wall Calendar |
| CB | Comb Bound |
| CD | Audio CD |
| CG | Clothing |
| CM | Audio CD (MP3) |
| CP | Box Calendar (Page-a-Day) |
| CS | Cards (flash or taro) |
| DO | Doll |
| EB | E-Book |
| GC | Greeting Card |
| GM | Game |
| HC | Hardcover |
| IL | Imitation Leather Bound |
| LB | Library Binding |
| LL | Loose-leaf |
| LT | Leather Bound |
| MM | Mass Market (Paperback) |
| MP | Sheet Map |
| MU | Mug |
| OT | Other |
| PB | Paperback |
| PO | Pop Up |
| PS | Posters/Prints |
| PU | Puzzle |
| RB | Ring Bound |
| SP | Spiral Binding |
| TA | Tableware |
| TC | Trade Cloth (Hardcover) |
| TO | Totebag |
| TP | Trade Paper (Paperback) |
| TY | Toy |
| VB | Vinyl Bound |

Seeds insert missing rows only. Staff-edited names are not overwritten. Seeds never reactivate a form staff deactivated. `OT` is never inferred from provider or leftover binding text.
